# Proposal: ⌘Q 隐藏而非退出

## 背景

OpsNotch 是常驻型 macOS 工具。用户容易因习惯性按下 `⌘Q` 而误退出，导致剪贴板监听、全局唤醒等常驻能力停止。

## 目标

- `⌘Q` 仅隐藏 OpsNotch，不结束进程。
- 隐藏后状态栏图标、剪贴板监听和全局唤醒继续工作。
- 真正退出仅保留 OpsNotch 状态栏菜单中的“退出”。
- 不阻塞 macOS 正常的系统级终止、注销或关机流程。

## 非目标

- 不修改现有状态栏“退出”的真实终止行为。
- 不新增全局快捷键或额外权限。
- 不改变窗口、Shelf、剪贴板和 Finder 的业务逻辑。
