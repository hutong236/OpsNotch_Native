# 设计

- 后台读取实时 AX 几何，并动态调用仓库已采用的 `_AXUIElementGetWindow`；子元素不支持时尝试其 AXWindow 属性。
- 使用窗口编号进行 `CGWindowListCreateDescriptionFromArray` 定向查询。该接口使用原始窗口编号数组，不能传 NSNumber 数组。避免全量列表未列出离屏窗口时直接失败。
- 有 AX 编号时只接受同 PID、同编号的窗口，不因 layer 不是固定 25 而丢弃。编号失效不得回退到其他窗口。
- 无 AX 编号时只接受唯一同 PID 的 status-window，其边界容纳 AX 图标矩形；允许 1 pt 的取整误差，存在歧义时不点击。
- 屏幕点击点为 AX 图标中心，窗口内点击点为该中心减去真实窗口原点，避免父窗口有边距时点到空白或其他控件。
- 投递前重验窗口身份和位置；平移保留窗口内点，窗口尺寸改变时使旧子控件点失效。
- 失败记录阶段、PID、AX 矩形及最多 8 个同进程窗口的编号/层级/几何。面板允许用户主动复制诊断；不含窗口标题、文件路径、屏幕像素，不自动上传。
- 扩展现有运行探针验证包含关系、非居中子控件、AX 编号、不同层级、错误进程、歧义和失效编号。CI 仍无法替代真实状态项、Clash Verge、OneDrive、TCP Latency 的实机验收。

环境无 OpenSpec CLI，按仓库既有 spec-driven 文件结构维护变更。
