# 隐藏图标使用 WindowServer 菜单栏窗口清单

## 问题

PR #102 后用户实机仍失败。诊断为 `axWindow=none`，AX 图标位于 `(-2980, 3, 36, 24)`，同 PID 公共窗口列表前 8 项为宽 1920/2560 点、layer 0 的普通窗口。列表不能匹配图标，错误发生在 `window-match`，尚未投递鼠标事件。该日志不能证明全量清单中所有窗口都缺失，也不能证明第三方菜单投递最终可用。

## 改动

补充 WindowServer 专用菜单栏清单和按窗口编号读取实时所有者/几何的路径；匹配成功后用同一路径复核并投递现有原生点击。保留 PID、唯一匹配和 AX 矩形包含约束。不修改 spacer，不要求展开所有图标。

## 验证

将用户报告的 AX 几何和普通窗口形状作为输入，模拟公共列表缺失但专用清单存在目标，验证完整查询顺序。CI 实际调用私有查询接口并在自己的离屏窗口验证 owner/frame 和点击前复核。真实第三方状态项仍须实机验收。
