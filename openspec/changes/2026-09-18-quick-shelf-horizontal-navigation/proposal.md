# Proposal: Quick Shelf 左右键跨区跳转

## 背景

Quick Shelf 已支持 ↑ / ↓ 在统一条目列表中移动、Enter 执行，但从刚复制的内容切到 Finder 快捷目录仍需要连续移动或使用鼠标。复制后呼出工具的高频流程需要更直接的键盘路径。

## 目标

- 按 → 直接跳到当前可见的 Finder 快捷目录第一项。
- 按 ← 直接跳到当前可见的“智能最近”第一项；正常复制流程下该项就是最新复制记录。
- ↑ / ↓ 继续负责上下移动，Enter 行为不变。
- 目标区域为空或因搜索/类型筛选不可见时保持当前高亮。
- 左右键切换不关闭 Shelf、不改变剪贴板内容，也不改变持久化数据。

## 非目标

- 不调整 Smart Recent 排序算法。
- 不修改 Finder 快捷目录排序。
- 不新增持久化字段或设置项。
- 不改变搜索、Quick Look、桌面命令和安全动作语义。
